# cindy-fedora-install-guide
A practical guide to installing, updating, and running Cindy on Fedora Linux using its official managed user installer. Based on real-world testing on Fedora 44 Workstation with GNOME.

## Running Cindy on Fedora Linux

I wanted to try [Cindy](https://cindy.app) on Fedora Linux, even though Fedora isn't explicitly listed among the primary installation targets in the official documentation.

After some testing, I managed to get Cindy running on Fedora 44 Workstation. I initially launched it from an extracted Debian package, then migrated to the official managed user installation method and successfully updated to a newer release.

I've documented the entire process, including the required dependencies, package verification, installation steps, GNOME desktop integration, and a small fix for duplicate application launchers.

This guide is based on my own testing and is intended to help other Fedora users who would like to try Cindy on their system.
